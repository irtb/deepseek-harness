# Agent Web 默认自动模式

**日期：** 2026-09-28
**状态：** 已批准（方案 A + 默认项目绑定选项 2）
**范围：** `apps/shotgo-agent-web` 仅前端默认行为

## 目标

新会话默认使用自动执行模式，并在 Space 列表可用时自动绑定「默认项目」或第一项；列表为空时创建「默认项目」，避免自动模式下发送被 Space 门禁拦住。

## 行为

1. `executionMode` 初始值为 `automatic`。
2. Space 列表成功到达且当前未选项目、且用户未主动解绑时：
   - 优先绑定名称「默认项目」，否则绑定第一项；
   - **仅当列表为空**时调用 `POST /api/spaces` 创建「默认项目」并绑定；创建失败同次加载不重试。
3. Space 列表请求失败时不创建、不假装就绪。
4. 用户选择「不绑定项目」后设置解绑标记，不再强制回绑；点击「自动模式」仍按现有逻辑尝试绑定。
5. 切换账户清空 Space 并清除解绑标记，随后可再次自动绑定。
6. 恢复带 `activeRun` 的会话时，UI 执行模式与 `activeRun.executionMode` 对齐，避免手动 Run 的开始确认卡被默认自动模式挡住。
7. 「新建创作」重置为自动模式。
8. 空态与 README 文案与自动默认对齐；相关测试同步更新。

## 非目标

不改 Gateway / Laravel；不在已有其他 Space 时强建「默认项目」；不改例外决策与 Run 锁定规则。
