# Agent Note: ShotGo 生成状态与取消

Status: implemented

[English](2026-08-25-shotgo-generation-status-cancel.md) | 中文

## 问题

Agent 需要取得权威进度并执行取消，同时不能信任模型虚构状态、跨越 Session 或团队边界、退还可能已经由供应商计费的任务，也不能在取消与完成竞争时丢失最终状态。

## 决策

Laravel 提供绑定 Grant 的状态、按客户端请求恢复查询和取消接口。每个请求都必须匹配生成日志的用户、可空团队、创建 Session 和稳定授权上下文。Gateway 注入当前 Grant；模型只能看到生成标识。取消根据 Session 与生成标识派生稳定写 Key，并与提交一样通过 Harness 单次批准通道。

Laravel 在取消时锁定生成日志行。排队请求会在 Worker 认领前退款并标记取消。处理中的请求标记取消但不自动退款，因为当前还没有供应商取消/退款契约。如果完成或其他终态先获得行锁，则原终态保持不变并直接返回。重复取消返回同一个权威终态。

图片和视频 Preset 会保留与多产出请求关联的每个生成标识，并在结束本轮前逐一查询。每个权威的排队中、处理中或已完成快照都作为独立的结构化工具结果保留，使 Canvas 客户端无需解析助手文字即可投影并行进度和全部返回资产。

## 考虑过的替代方案

由 Harness 直接轮询或取消供应商不可接受，因为 Laravel 负责供应商凭据、积分、任务和退款。只信任生成标识也不可接受，否则同一用户的其他 Session 可能观察或取消任务。自动退还处理中的任务不可接受，因为供应商可能已经计费，且尚未核实上游退款。

## 影响

本阶段不需要数据库迁移；新提交的 Agent 生成会把可信 Session 与授权元数据存入现有请求参数。缺少该绑定的历史请求在 Agent 状态访问时安全失败。多任务跟踪会为每个已知标识增加工具调用，但可避免一个已完成任务隐藏同级仍在处理或已经完成的结果。
