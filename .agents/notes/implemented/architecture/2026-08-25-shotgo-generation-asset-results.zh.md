# Agent Note：ShotGo 生成资产结果

状态：已实现

[English](2026-08-25-shotgo-generation-asset-results.md) | 中文

## 问题

图片或视频生成完成后需要返回可用结果，同时不能暴露供应商原始响应、临时供应商 URL、私有存储路径，也不能返回其他用户或团队的资产。用户在 Worker 执行期间切换激活账户上下文时，异步媒体落库还必须保持生成任务原有的授权上下文。

## 决策

Laravel 从现有 `user_media_assets` 台账解析资产结果。只有任务已完成、类型属于媒体，并且生成来源的资产同时匹配任务用户、冻结的可空团队和规范化存储路径时才返回结果。响应只包含不透明资产 ID、媒体类型、公开 HTTP(S) URL 和字节大小；台账缺失或归属不匹配时以空资产列表安全失败。

生成 Worker 把生成日志冻结的可空团队传给媒体转存；已有交互式上传继续保持当前上下文语义。Agent 严格校验每个资产字段和 URL 协议，再通过 `generation_status` 暴露核验后的列表，不增加任何供应商直连的资产查询。

## 已考虑的替代方案

直接返回 `result_text` 会泄露供应商 URL 或私有路径，因此否决。返回 `response_payload` 会暴露内部诊断记录，因此否决。当前单结果流程可通过既有资产归属台账安全关联，所以暂不增加生成任务到资产的外键。

## 后果

无需数据表迁移。当前处理器即使收到供应商返回的多张图片，仍只发布一个主媒体资产；多资产持久化需要后续明确设计数据模型和计费规则。部署时先上 Laravel，再上 Agent 协议消费者；回滚时先回滚 Agent。
