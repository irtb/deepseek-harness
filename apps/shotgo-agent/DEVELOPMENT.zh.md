# ShotGo Agent 开发工作流

[English](DEVELOPMENT.md) | 中文

每项可独立评审的开发均使用新分支。新分支从当前本地 `master` 创建；准备版本发布时，也可以从明确指定的 `release/*` 分支创建。禁止直接在上述受保护分支开发。

分支使用 `feature/<scope>`、`fix/<scope>`、`docs/<scope>` 或 `chore/<scope>`。每个分支只处理一个事项，所有 ShotGo 产品改动必须位于 `AGENTS.md` 规定的产品边界内。

合并前必须按适用范围执行聚焦类型检查、单元/契约测试、lint、翻译与 Agent Note 检查、上游隔离检查以及 `git diff --check`。任何必需检查被跳过、无法执行、不稳定或失败，均禁止合并。

所有门禁通过后，使用非快进合并将开发分支合并到本地 `master` 或指定的 `release/*` 分支。推送、创建 Pull Request、部署和删除分支是独立操作，仍需用户明确授权。

## 必需的交接证据

- 开发分支与基线分支；
- 合并包含的提交；
- 执行的准确检查及结果；
- 警告或延期验收项；
- 是否已执行合并、推送或部署。
